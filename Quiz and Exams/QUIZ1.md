# Quiz 1 Description

This quiz covers the topics of data collection and data cleaning. It includes questions on how to gather data from various sources and how to clean and preprocess the data to make it suitable for analysis.

## Questions
- How do you gather data from different sources?
- What are the common methods for cleaning and preprocessing data?

## Answers
- Data can be gathered from sources such as surveys, APIs, databases, and web scraping.
- Common methods for cleaning data include removing duplicates, handling missing values, and correcting inconsistencies.
