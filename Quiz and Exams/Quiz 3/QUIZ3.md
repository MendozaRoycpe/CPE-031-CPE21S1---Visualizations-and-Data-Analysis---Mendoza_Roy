# Quiz 3 Description

This quiz covers statistical analysis and machine learning basics. It includes questions on how to perform basic statistical tests and how to use Python libraries for machine learning.

## Questions
- What are the basic statistical tests used in data analysis?
- How do you use Python libraries for machine learning?

## Answers
- Basic statistical tests include t-tests, ANOVA, and chi-square tests.
- Python libraries like scikit-learn are used for machine learning tasks such as classification and regression.
