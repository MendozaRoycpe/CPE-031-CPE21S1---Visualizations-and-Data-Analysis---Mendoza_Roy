# Prelim Exam Description

This exam covers the entire preliminary term's topics, including data collection, data cleaning, exploratory data analysis, and basic statistical analysis.

## Questions
- What are the key steps in data collection and cleaning?
- How do you perform exploratory data analysis?
- What are the basic statistical tests used in data analysis?

## Answers
- Data collection involves gathering data from various sources, and cleaning involves removing duplicates and handling missing values.
- Exploratory data analysis involves data transformation and visualization.
- Basic statistical tests include t-tests, ANOVA, and chi-square tests.
