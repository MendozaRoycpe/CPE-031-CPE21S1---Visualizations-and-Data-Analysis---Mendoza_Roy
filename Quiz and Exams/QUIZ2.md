# Quiz 2 Description

This quiz focuses on exploratory data analysis (EDA) techniques and data visualization. It includes questions on how to use Python libraries like NumPy and Matplotlib to analyze and visualize data.

## Questions
- What are the steps involved in exploratory data analysis?
- How do you use Python libraries to visualize data?

## Answers
- Steps in EDA include data cleaning, data transformation, and data visualization.
- Python libraries like NumPy and Matplotlib are used to create various types of plots and charts to understand the data better.
